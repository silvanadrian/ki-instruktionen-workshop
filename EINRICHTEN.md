# Wo die Instruktionen hingehören

> Die Anbieter benennen ihre Menüs oft um. Die Namen unten sind Anhaltspunkte (Stand
> November 2026); such im Zweifel nach «Anweisungen», «Instructions» oder «Projekt».

Es gibt in fast jedem Tool drei Orte. Je weiter unten, desto gezielter.

| Ort | Gilt für | Gut für |
|---|---|---|
| Persönliche Einstellungen | alle deine Chats | Sprache, Anrede, Ton |
| Projekt / eigener Assistent | alle Chats in diesem Projekt | dein Lernvorhaben |
| Skill-File | nur wenn die Aufgabe passt | wiederkehrende Aufgaben, zum Weitergeben |

## Claude

- **Projekt:** Projekte → neues Projekt → Projektanweisungen. Text einfügen.
- **Skill:** In den Einstellungen unter den Funktionen gibt es den Bereich
  «Skills». Dort lädst du den Ordner mit der `SKILL.md` als ZIP hoch.

## ChatGPT

- **Projekt:** Projekte → neues Projekt → Anweisungen.
- **Eigener GPT:** GPTs → Erstellen → Feld «Hinweise».
- **Persönlich:** Einstellungen → Personalisierung → individuelle Hinweise.

## Microsoft Copilot

- **Eigener Agent:** Agent erstellen → Feld «Anweisungen».

## Gemini

- **Gem:** Gems → neues Gem → Feld «Anweisungen».

## Wenn nichts davon geht

Füge die Instruktionen als erste Nachricht in einen neuen Chat ein und schreib
darunter: «Halte dich in diesem Chat an diese Anweisungen. Bestätige kurz.»

## Skills von anderen

Ein Skill-File von jemand anderem ist eine Anleitung, der deine KI folgt.
Bevor du eines installierst:

1. Lies die `SKILL.md` ganz. Sie ist normaler Text.
2. Installiere nur aus Quellen, denen du vertraust.
3. Sei vorsichtig bei Skills, die Skripte mitbringen oder Daten irgendwohin
   senden wollen.
